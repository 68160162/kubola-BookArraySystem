# ระบบจัดการคลังหนังสือเรียน

โปรแกรมภาษา Java สำหรับสาธิตการใช้ Array of Objects โดยเก็บหนังสือเรียนแต่ละรายการเป็น Object ใน Array

## การแบ่ง Class

- `Book.java` เก็บรหัสหนังสือ ชื่อวิชา และจำนวนของหนังสือ 1 รายการ
- `Main.java` แสดงเมนู รับข้อมูล และจัดการหนังสือใน Array

## ความสามารถ

1. เพิ่มหนังสือ
2. แสดงหนังสือทั้งหมด
3. ค้นหาหนังสือด้วยรหัส
4. ปรับจำนวนหนังสือคงเหลือ โดยรับเข้าหรือเบิกออก
5. ลบหนังสือด้วยรหัส
6. สรุปจำนวนรายการ จำนวนหนังสือรวม และรายการที่เหลือน้อย
0. ออกจากโปรแกรม

## Array ที่ใช้

```java
Book[] books = new Book[10];
```

หนังสือแต่ละเล่มจะถูกสร้างเป็น Object แล้วนำไปเก็บใน Array เช่น `books[0]` และ `books[1]`

เมื่อลบข้อมูล โปรแกรมจะค้นหา Index แล้วเลื่อนสมาชิกด้านหลังมาทับตำแหน่งที่ลบ
จากนั้นกำหนดช่องสุดท้ายที่เคยใช้งานเป็น `null` และลดตัวแปร `count` ลง 1

## แนวคิดที่ได้เรียนรู้

- Array of Objects และการเข้าถึงข้อมูลด้วย Index
- การใช้ Loop เพิ่ม แสดง ค้นหา ลบ และรวมข้อมูล
- การใช้ Condition ตรวจรหัสซ้ำ จำนวนไม่เพียงพอ และ Stock ใกล้หมด
- การสร้าง Class, Object, Constructor, Getter และ Setter
- การรับข้อมูลด้วย Scanner และสร้างเมนูด้วย switch

## แนวทางแบ่งงานในกลุ่ม

- สมาชิกคนที่ 1: อธิบาย Class `Book` และ Array of Objects
- สมาชิกคนที่ 2: อธิบายเมนูเพิ่ม แสดง และค้นหา
- สมาชิกคนที่ 3: อธิบายการปรับ Stock และการตรวจจำนวนคงเหลือ
- สมาชิกคนที่ 4: อธิบายการลบด้วยการเลื่อนสมาชิกและการสรุปผล

## วิธี Compile และ Run

```bash
javac Book.java Main.java
java Main
```
